- 只做能识别实际错误的任务相关检查，不为假想风险扩建防御框架，不默认重复全仓哈希或临时场景矩阵。
- 不把路线认可当作后续全部代码授权，不把静态检查或参数量接近当作训练/论文复现证据。完整规则见 [实现与执行边界](implementation_boundary.md)。

## 8. 名词表

| 名词 | 解释 |
| --- | --- |
| 点云 | 激光雷达扫描得到的大量三维点，每个点有坐标和反射强度 |
| sweep / 历史帧 | 一次LiDAR扫描，名义间隔约0.05 s；输入为当前扫描加19份历史记录。场景开头历史不足时上游会重复填充；本次时间审计针对未来sample，不覆盖历史sweep时序/变换 |
| 关键帧（sample） | 带标注的帧，名义间隔0.5 s；1.1已复核mini共404帧，几何/关联使用元数据实际时间 |
| 索引文件（info） | `.pkl`记录点云路径、历史帧和7个时刻的标签；生成训练划分索引不代表已经训练模型 |
| 未来标签 | 含当前时刻，名义偏移0、0.5、…、3 s，共7个位置；实际token和时间对应仍待审计 |
| 末端复制 | 物体的标注提前结束（离开视野或场景结束）时，上游代码用最后一个框填满剩余时刻 |
| static / linear / nonlinear | 静止、匀速直线、非直线运动三类轨迹，指标按这三类分别统计 |
| 柱体（pillar） | 把地面划成 0.125 m × 0.125 m 的格子，每个格子里的点汇总成一个特征 |
