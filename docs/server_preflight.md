## 阶段4：拿到实例后的环境与短训练准备

1. 读取真实OS、GPU、驱动、Python、Torch、nvcc、编译器和可用磁盘；nvidia-smi显示的CUDA版本不等于安装的Toolkit。
2. 迁移源码、配置和source-lock，重建环境；不复制WSL venv或已有.so。
3. 将/mnt/d、/home/pillar等本机路径映射到实际服务器持久路径；使用获批的项目内 FutureDet 工作副本作为唯一执行主体，不混入另一份 det3d。
4. 按卡重编：3090架构8.6、4090架构8.9。云实例使用其宿主驱动，不未经核对安装或替换宿主驱动。
5. 按实际使用的模块检查 Torch/spconv、native 小输入前反向和必要边界；空柱、负特征、ROI、NMS 等只在涉及的任务中验收，不能假定已有结果覆盖新环境。
6. 保存环境和构建记录；确认 mini 数据路径与配置后，按获批任务做短训练、保存恢复和评价，不直接启动正式20轮训练。

本机可准备数据，并按具体获批任务做 GPU 推理与调试；所有实际训练均在服务器，包括 mini 短训练。阶段5首轮正式训练仅 B4 完整模型20轮；FutureDet 对照使用官方权重推理与评价，不重新训练。B0—B3 是否补做按结果、预算和后续批准决定。

## 计费来源与边界

AutoDL 仅作为当时的规则示例。2026-10-13 查阅的[计费文档](https://www.autodl.com/docs/price/)记录为：普通按量实例按开关机计费，不按 GPU 计算时间计费；付费扩容数据盘独立计费且关机仍计费。本批未重新核验。具体 GPU/磁盘价格、关机保留时间、释放规则和实例类型差异，均须在选定实例时核对；关机不能代替备份。

下载或阅读源码等不需要GPU的任务，可用平台提供的低成本CPU方式，但必须确认该模式的CPU/RAM是否够完成当前任务。初期先备份源码、配置和关键结果；原始数据的重新下载成本也纳入考虑。
